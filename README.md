# sm64coopdx web

Super Mario 64 multiplayer in the browser, built on [sm64coopdx](https://github.com/coop-deluxe/sm64coopdx): every browser runs its own game and players meet peer to peer, no game server.

**Play:** https://sm64-web.vercel.app

You need your own Super Mario 64 (USA) `.z64` ROM. It stays in your browser and is never uploaded. This site contains no ROM or game assets from it.

`?room=name` joins a separate world; `?touch=1` forces on-screen controls. (in this fork It is not necessary to use ?room=name if you want to create rooms; you can create them from the menu)
